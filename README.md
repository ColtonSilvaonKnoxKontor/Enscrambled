# Enscrambled

This is a simple AES Encryption program intended for distributing copyrighted material without DMCA takedown from companies.

# What is This?

This program transform any files into unrecognizable format, making it inaccessible to applications and file scanners. This encrypts any files (regardless of file size) using simple AES method and injecting file signature to the file so that only this program can decrypt the file. 

# More?

This [RANSOMWARE-LIKE VARIANT](https://github.com/ColtonSilvaonKnoxKontor/Enscrambled/tree/ransomware) automatically encrypts all files using pre-set password, enforcing users to guess password to decrypt them. Failing to decrypt files will be deleted automatically. Click the link for more info.
